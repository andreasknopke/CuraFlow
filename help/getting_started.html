Erste Schritte mit CuraFlow

Anmeldung

Zum Anmelden benötigen Sie eine E-Mail-Adresse und ein Passwort, die Ihnen von Ihrem Administrator zugewiesen wurden. Ein eigenständiges Registrieren ist nicht möglich.

  1. Öffnen Sie die CuraFlow-URL Ihrer Einrichtung in Ihrem Browser.
  2. Geben Sie Ihre E-Mail-Adresse ein.
  3. Geben Sie Ihr Passwort ein.
  4. Klicken Sie auf "Anmelden".
Wichtig: Nach 10 fehlgeschlagenen Anmeldeversuchen innerhalb von 15 Minuten wird die Anmeldung vorübergehend gesperrt (Rate-Limiting). Warten Sie 15 Minuten oder wenden Sie sich an Ihren Administrator.
Hinweis: Bei einem Ablauf der Sitzung (JWT-Token, gültig 24 Stunden) werden Sie automatisch zur Anmeldeseite zurückgeleitet. Der Token wird im Browser unter dem Schlüssel radioplan_jwt_token gespeichert.

Mandanten-Auswahl (Multi-Tenant)

Benutzer, die mehreren Mandanten (z.B. Abteilungen) zugeordnet sind, sehen nach der Anmeldung einen Mandanten-Auswahldialog. Wählen Sie den Mandanten, in dem Sie arbeiten möchten. Anschließend werden alle Daten (Dienstplan, Team, Statistik) aus der Datenbank dieses Mandanten geladen.

Der ausgewählte Mandant wird über einen verschlüsselten DB-Token identifiziert, der bei jeder Anfrage mitgesendet wird (X-DB-Token-Header). Sie können den Mandanten später über Ihr Benutzerkonto wechseln.

Erste Anmeldung: Passwort ändern

  • Ist Ihr Konto mit dem Hinweis "Passwort muss geändert werden" markiert, erscheint nach der Anmeldung automatisch der Dialog zur erzwungenen Passwortänderung.
  • Die Navigation ist erst möglich, nachdem Sie ein neues Passwort vergeben haben.
  • Ein Passwort muss mindestens 8 Zeichen lang sein.

Nach der Anmeldung sehen Sie links die Seitenleiste mit allen Modulen. Die Seitenleiste klappt nach 3 Sekunden automatisch ein; bewegen Sie die Maus darüber oder klicken Sie auf das Menü-Symbol oben links, um sie wieder einzublenden.

Benutzerkonto (Account-Menü)

Klicken Sie oben rechts auf Ihr Benutzerkonto. Folgende Aktionen stehen zur Verfügung:

Passwort ändern

  • Geben Sie das aktuelle Passwort, das neue Passwort und dessen Wiederholung ein.
  • Das neue Passwort muss mindestens 8 Zeichen lang sein; beide Eingaben müssen übereinstimmen.

E-Mail-Adresse ändern

  • Geben Sie die neue E-Mail-Adresse und zur Bestätigung Ihr Passwort ein.
  • Nach erfolgreicher Änderung werden Sie abgemeldet und müssen sich mit der neuen E-Mail-Adresse neu anmelden.

Abmelden

  • Beendet die Sitzung und löscht den Token aus dem Browser-Speicher.
Tipp: Die Versions- und Build-Informationen (z.B. Commit-Hash) Ihrer Installation finden Sie im Account-Menü. Geben Sie diese bei Support-Anfragen an.

Persönliche Einstellungen

Folgende benutzerbezogene Einstellungen können an verschiedenen Stellen angepasst werden:

Design/FarbschemaÜber "Design wählen" im Seitenmenü; wird pro Benutzer gespeichert.

Eingeklappte SektionenWelche Sektionen des Wochenplans standardmäßig eingeklappt sind.
Ausgeblendete ZeilenÜber "Zeilen verwalten" im Wochenplan; pro Benutzer gespeichert.

Feedback senden

Über "Feedback & Verbesserungen" öffnet sich ein Dialog mit zwei Typen:

  • Bug-Report: Melden Sie einen Fehler. Titel und Beschreibung sind Pflicht. System-, Benutzer- und Mandanteninformationen werden automatisch mit übermittelt.
  • Feature-Request: Schlagen Sie eine neue Funktion oder Verbesserung vor.

Tritt ein unerwarteter Fehler (Crash) auf, öffnet sich der Dialog automatisch mit einem vorbefüllten Fehlerbericht (Fehlermeldung + Stack Trace).
